# 口播小程序 · 前端界面说明文档

**技术栈：** Taro (React) · 微信小程序 + 抖音小程序双端  
**设计风格：** 深色主题，简洁现代，创作工具感  
**主色：** 品牌紫 `#7C4DFF`，背景黑 `#0F0F0F`，卡片深灰 `#1A1A1A`

---

## 页面结构总览

```
TabBar（底部导航）
├── 首页 / 爆款模板    /pages/index/index
├── 创作              /pages/create/index
├── 我的视频          /pages/videos/index
└── 个人中心          /pages/profile/index

独立页面（无 TabBar）
├── 文案生成          /pages/script/generate
├── 文案编辑          /pages/script/edit
├── 提词器录制        /pages/record/index
└── 视频处理状态      /pages/video/status
```

---

## 页面 1：首页 / 爆款模板

**路由：** `/pages/index/index`  
**功能：** 展示热门口播模板 Feed，引导用户一键创作

### 布局结构

```
┌────────────────────────────────┐
│  口播创作   🔔            头部  │
├────────────────────────────────┤
│  [🎙 立即创作]  大号 CTA 按钮  │  ← 渐变紫色背景，居中，高64px
├────────────────────────────────┤
│  领域筛选栏（横向滚动）         │
│  [全部] [产品] [生活] [知识]   │  ← Chip 标签，选中紫色
├────────────────────────────────┤
│  🔥 爆款模板                   │
│  ┌──────────────────────────┐  │
│  │ 产品种草三段式            │  │  ← TemplateCard 组件
│  │ 开场钩子 + 卖点 + 行动   │  │
│  │ [已用 1.2k次] ⭐精选     │  │
│  │           [用这个模板 →] │  │
│  └──────────────────────────┘  │
│  ┌──────────────────────────┐  │
│  │ 情感共鸣分享              │  │
│  │ ...                      │  │
│  └──────────────────────────┘  │
│  （无限滚动加载）               │
└────────────────────────────────┘
```

### 组件说明

**TemplateCard**
- 背景：`#1A1A1A`，圆角 `12px`，左侧 `4px` 紫色强调线
- 标题：`16px` 白色加粗
- 摘要：`13px` 灰色 `#888`，最多2行截断
- 徽章：`精选` 金色标签，`使用次数` 灰色文字
- 按钮：`用这个模板 →`，文字按钮紫色

**交互**
- 点击 `用这个模板` → 跳转文案生成页，携带 `template_id` 参数，预填充结构
- 点击 `立即创作` → 跳转文案生成页，空白模式

## 页面 3：文案编辑

**路由：** `/pages/script/edit?script_id=xxx`  
**功能：** 查看 AI 生成结果，支持自由编辑，确认后进录制

### 布局结构

```
┌────────────────────────────────┐
│  ← 编辑文案          [重新生成]│
├────────────────────────────────┤
│  📊 预估时长：58秒 | 字数：232  │  ← 实时统计条
├────────────────────────────────┤
│  ┌──────────────────────────┐  │
│  │                          │  │
│  │  今天要给大家介绍一款     │  │  ← TextArea 全屏编辑
│  │  超级好用的防晒霜...      │  │    字体18px，行高1.8
│  │                          │  │    支持换行分段
│  │  [段落1]                 │  │
│  │  [段落2]                 │  │
│  │  ...                     │  │
│  └──────────────────────────┘  │
├────────────────────────────────┤
│  [💾 保存草稿]  [🎙 开始录制 →]│
└────────────────────────────────┘
```

### 组件说明

- **字数/时长统计**：粘性顶部，实时计算（时长 = 字数/4s）
- **TextArea**：段落间自动 `\n\n` 分割，自适应高度
- **保存草稿**：静默保存，显示"已保存"toast
- **开始录制**：确认文案并跳转提词器页，携带 `script_id`

## 页面 4：提词器 + 录制（核心页面）

**路由：** `/pages/record/index?script_id=xxx`  
**功能：** 全屏提词器，语音驱动自动滚动，同步录制视频

### 布局结构（录制前）

```
┌────────────────────────────────┐
│  ← 返回         [调节速度 ⚙]   │  ← 顶部半透明
├────────────────────────────────┤
│                                 │
│  上一段（灰色 60% 透明）        │
│                                 │
│  ████████████████████████████  │  ← 当前段：高亮白色，大字
│  正在阅读的这一句会被完整显示  │     字体22px，行高1.6
│  ████████████████████████████  │
│                                 │
│  下一段（灰色 60% 透明）        │
│  下下段（灰色 30% 透明）        │
│                                 │
├────────────────────────────────┤
│  进度条：▓▓▓▓░░░░░  12%        │
├────────────────────────────────┤
│  ┌──────────────────────────┐  │
│  │   [● 开始录制]           │  │  ← 红色录制按钮，直径72px
│  └──────────────────────────┘  │
└────────────────────────────────┘
```

### 布局结构（录制中）

```
┌────────────────────────────────┐
│  🔴 录制中  00:00:42    [暂停] │  ← 顶部录制状态栏
├────────────────────────────────┤
│                                 │
│  上一段（灰色）                 │
│                                 │
│  ████ 当前高亮段落 ████         │  ← ASR 驱动滚动
│  已读词组以不同颜色标记         │     已读：白色，未读：灰色
│                                 │
│  下一段（灰色）                 │
│                                 │
├────────────────────────────────┤
│  🎤 识别中：今天天气真好...    │  ← 实时 ASR 识别文字
├────────────────────────────────┤
│  [■ 停止]  [⏸ 暂停]  [↩ 重录]  │
└────────────────────────────────┘
```

### 录制完成弹窗

```
┌──────────────────────────┐
│  录制完成 🎉             │
│  时长：00:01:03          │
│                          │
│  [重新录制]  [提交剪辑 →] │
└──────────────────────────┘
```

### 组件说明

- **提词区**：`overflow:hidden`，通过 `scrollTop` 平滑滚动，每段高度固定计算
- **当前段高亮**：白色 `#FFFFFF`，字体略大 `22px`；上下段渐变灰色
- **ASR 实时状态栏**：底部固定，灰色背景，绿色脉冲点 + 识别文字
- **暂停**：暂停录制 + 暂停 WebSocket 音频流，文字变为"继续"
- **重录**：清空帧标记 + ASR 历史，视频重新开始录制
- **调节速度**：手动微调滚动速度（±1 档），ASR 失效时的兜底

```
┌────────────────────────────────┐
│  ← 返回                        │
```

## 全局组件

### TabBar
```
[🏠 首页] [✨ 创作] [🎬 作品] [👤 我的]
```
- 背景：`#0F0F0F`，选中紫色图标 + 文字
- 高度：`56px` + 安全区域

### Toast / 提示
- 成功：绿色背景，顶部居中淡入淡出
- 错误：红色背景
- 信息：深灰背景

### 通用颜色规范

| Token | 值 | 用途 |
|-------|----|------|
| `--color-bg` | `#0F0F0F` | 页面背景 |
| `--color-card` | `#1A1A1A` | 卡片背景 |
| `--color-border` | `#2A2A2A` | 分割线 |
| `--color-primary` | `#7C4DFF` | 主色/强调 |
| `--color-text-1` | `#FFFFFF` | 主文字 |
| `--color-text-2` | `#AAAAAA` | 次要文字 |
| `--color-text-3` | `#555555` | 占位文字 |
| `--color-success` | `#4CAF50` | 成功状态 |
| `--color-error` | `#F44336` | 错误状态 |
| `--color-warning` | `#FF9800` | 警告 |

### 字体规范

| 级别 | 大小 | 权重 | 用途 |
|------|------|------|------|
| Display | `28px` | 700 | 页面主标题 |
| H1 | `22px` | 600 | 提词器文字 |
| H2 | `18px` | 600 | 卡片标题 |
| Body | `15px` | 400 | 正文 |
| Caption | `13px` | 400 | 辅助信息 |
